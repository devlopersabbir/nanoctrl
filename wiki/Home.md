# Welcome to NANOCTRL Wiki

> **Tiny Remote Control, Nothing Else.**

**NANOCTRL** is an ultra-lightweight, zero-dependency remote desktop suite designed to do exactly one thing without bloat: **Connect $\to$ Accept $\to$ Control**.

---

## ⚡ Quick Highlights

* **Binary Size**: ~106 KB native macOS app | ~51 KB standalone server.
* **Zero 3rd-Party Dependencies**: Pure C & native macOS system frameworks (`Cocoa`, `ScreenCaptureKit`, `CoreGraphics`).
* **Self-Hosted Freedom**: Host your own ultra-fast relay server (`nanosrv`) for global WAN access across NAT and firewalls.
* **Device ID & PIN Pairing**: Connect anywhere with a **9-digit Device ID** (`842 190 345`) and **6-digit PIN** (`582 914`), or connect directly via LAN (`IP:port`).
* **Cryptographic Security**: HMAC-SHA256 challenge-response verification with mandatory Host Approval.
