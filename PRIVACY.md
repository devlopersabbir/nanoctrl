# Privacy Policy

**NANOCTRL is built with a strict privacy-first philosophy.**

---

## 1. No Data Collection
NANOCTRL does not collect, store, transmit, or sell any personal data, usage analytics, telemetry, crash reports, device identifiers, or IP addresses to any central server or third party.

## 2. No Accounts or Tracking
* **No User Accounts**: NANOCTRL requires no registration, email address, password, or profile.
* **No Telemetry**: There are zero tracking SDKs, advertising frameworks, or background telemetry services embedded in any NANOCTRL binaries.

## 3. Screen and Input Data Transmission
* **Direct Mode**: Screen pixels and mouse/keyboard events are transmitted directly between your Controller and Host devices over your local network.
* **Relay Mode**: When using a self-hosted relay server (`nanosrv`), traffic is forwarded as opaque, encrypted packets between peers. The relay server does not decrypt, log, or record screen or input streams.

## 4. Permissions on macOS
* **Screen Recording**: Used solely in real-time to capture display tiles for the active remote session. No recordings are saved to disk.
* **Accessibility**: Used solely in real-time to inject remote mouse and keyboard events upon your explicit approval.

## 5. Contact
If you have any questions about this privacy policy, please open an issue on GitHub.
