# Security Policy

## Supported Versions
We provide security updates for the latest released version of NANOCTRL.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within NANOCTRL, please report it privately:

1. **GitHub Security Advisories**: Use the "Report a vulnerability" tab under GitHub Security on the repository.
2. Alternatively, create a confidential issue or contact the project maintainers directly.

Please include:
* Description of the vulnerability and potential impact.
* Steps or proof-of-concept to reproduce the issue.

We will acknowledge your report promptly and coordinate a fix before public disclosure.
